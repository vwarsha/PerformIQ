# PerformIQ — Athlete Performance Intelligence

A Streamlit web app that tracks athlete training sessions and provides 
sport and drill-specific performance recommendations.

## Features
- Session logging with execution, consistency and workload scores
- Performance trend tracking with charts
- Sport + drill specific recommendations (Cricket, Running, Football, Basketball)
- Streak tracker — tracks consecutive improving sessions

## Built with
Python, Streamlit, Pandas, Plotly
